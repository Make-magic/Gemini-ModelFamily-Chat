# 中华传统美学重塑：Gemini-ModelFamily-Chat 色彩与视觉设计方案

## 1. 设计哲学 (Design Philosophy)

基于项目的核心定位（先进的 AI 聊天界面），本次美学重塑旨在打破当前泛滥的“AI 塑料感（AI Slop）”与同质化的现代极简主义，转而拥抱**中华传统美学**的深邃与克制。

核心设计基调：**内敛、典雅、生机、意境**。

## 2. 色彩系统 (Color System)

色彩提取自中国传统色谱，分为以下几套核心主题。

### 2.1 浅色模式：水墨绢本 (Light Theme: Ink & Silk)
在浅色模式下，界面模拟传统绢丝画卷的质感，以温润的暖灰白为底，辅以石青、石绿的清透跳色。

*   **基础背景色 (Backgrounds)**
    *   `--bg-app`: `#F5F4EE` (素色 / Plain)
    *   `--bg-surface`: `#E9E4D4` (缟色 / Unbleached Silk)
    *   `--bg-bubble-ai`: `#FFFFFF`
    *   `--bg-bubble-user`: `#5D828A` (竹月 / Bamboo Moon) - 温润内敛的灰蓝绿色，不抢主色风头。

*   **文本色 (Typography Colors)**
    *   `--text-primary`: `#22252A` (玄青 / Dark Cyan-Black)
    *   `--text-secondary`: `#5C6366` (蟹壳青 / Crab Shell Cyan)

*   **品牌与强调色 (Accents & Brand)**
    *   `--color-primary`: `#1661AB` (石青 / Mineral Blue)

### 2.2 深色模式：千里江山 (Dark Theme: Vast Mountains & Rivers)
深色模式下，界面沉入幽暗的夜幕与深潭之中，石青与石绿如同夜明珠般在暗色基调中发光，提供卓越的专注体验。

*   **基础背景色 (Backgrounds)**
    *   `--bg-app`: `#141A1C` (鸦青 / Raven Cyan)
    *   `--bg-surface`: `#1E292C` (苍黛 / Dark Ash Green)
    *   `--bg-bubble-ai`: `#141A1C`
    *   `--bg-bubble-user`: `#24746F` (深石绿 / Dark Mineral Green)

*   **文本色 (Typography Colors)**
    *   `--text-primary`: `#D6ECF0` (月白 / Moon White)
    *   `--text-secondary`: `#8A989F` (云水 / Cloud Water)

*   **品牌与强调色 (Accents & Brand)**
    *   `--color-primary`: `#0F59A4` (点翠 / Kingfisher Blue)

### 2.3 沉浸阅读模式：文心雕龙 (Reading Theme: Wen Xin Diao Long)
**儒雅·深沉·底蕴**
此方案特别适合文史哲、社科、艺术类的长文阅读与沉浸式交互，散发着浓厚的书卷气。

*   **背景层 (Background)**: 鱼肚白 `#F5F4F1` - 如同高级宣纸般的微暖色调，极大降低屏幕刺眼感。
*   **正文层 (Typography Body)**: 墨黑 `#252324` - 带有极微弱暖色倾向的黑，与鱼肚白背景形成极佳对比但不生硬。
*   **标题/强调 (Title & Accent)**: 檀唇 `#8F4B4A` - 深沉的暗红色，如同印泥或红木，作为标题和关键按钮能瞬间提升格调。
*   **图表辅色 (Chart Secondary)**: 古铜 `#B0A080` - 沉稳的黄褐色，适合用于次要数据展示或背景卡片。
*   **对比辅色 (Contrast Secondary)**: 蟹壳青 `#5C695B` - 偏暖的灰绿色，用于引用区块、次要高亮或用户输入气泡，与檀唇形成高级的红绿对比。

### 2.4 极客理学模式：格物致知 (STEM Theme: Ge Wu Zhi Zhi)
**冷静·严谨·理性**
此方案专为理工科、信息学、医学等需要极度理性和长时间专注的场景设计，提供极致的清晰度与逻辑分层。

*   **背景层 (Background)**: 月白 `#F0F2F4` - 带有微弱冷蓝灰调的白，如同实验服或极地冰雪，冷静且降低对比度疲劳。
*   **正文层 (Typography Body)**: 玄青 `#1C2327` - 极深的冷灰色，如同精密的黑板或金属仪器，确保严谨的阅读体验。
*   **标题/强调 (Title & Accent)**: 靛蓝 `#2A5CAA` - 深邃的工业蓝，作为核心视觉引导，传递高度的专业感与可信赖度。
*   **图表辅色 (Chart Secondary)**: 竹青 `#789262` - 沉静的灰绿色，适合用于数据可视化中的“成功”或次要趋势，不刺眼。
*   **对比辅色 (Contrast Secondary)**: 秋香 `#E1A451` - 克制的黄橙色，用于需要警示或极强对比的数据点，打破冷色调的沉闷。

### 2.5 经世致用模式：经世致用 (Practical Theme: Jing Shi Zhi Yong)
**中正·稳健·自然**
此方案专为经管、法学、地学等需要宏观视野与稳健判断的场景设计，提供扎实、温和且具有权威感的视觉体验。

*   **背景层 (Background)**: 浅缃 `#FAF9E6` - 带有微黄的暖白色，如同陈年古籍或羊皮纸，温和且充满历史底蕴。
*   **正文层 (Typography Body)**: 铁褐 `#36282B` - 极深且带有暖意的灰褐色，比纯黑更具亲和力，稳重而不压抑。
*   **标题/强调 (Title & Accent)**: 沧浪 `#437272` - 深沉的青绿色，象征水与自然，提供中正平和、值得信赖的视觉焦点。
*   **图表辅色 (Chart Secondary)**: 赭黄 `#C67915` - 稳健的大地色系，常用于经济数据或地质图层，带来充实的物质感。
*   **对比辅色 (Contrast Secondary)**: 朱槿 `#9F5454` - 克制的暗砖红色，用于重要法条高亮、财务赤字或关键警示，醒目却不刺眼。

## 3. CSS 变量实现示例 (CSS Variables Implementation)

```css
[data-theme='wenxin'] {
  /* Reading Theme - 文心雕龙 */
  --bg-app: #F5F4F1; /* 鱼肚白 */
  --bg-surface: #E8E6DF; /* 略深的纸张色用于侧边栏 */
  --bg-bubble-ai: #FFFFFF;
  --bg-bubble-user: #5C695B; /* 蟹壳青 */
  
  --text-primary: #252324; /* 墨黑 */
  --text-secondary: #B0A080; /* 古铜 - 作为次要文字可能过亮，可用作辅助元素 */
  --text-on-accent: #F5F4F1;
  
  --color-primary: #8F4B4A; /* 檀唇 */
  --color-border: #DCD8D0;
  
  --shadow-ink: 0 4px 24px rgba(37, 35, 36, 0.05);
}
```
